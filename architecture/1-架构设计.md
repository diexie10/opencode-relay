# 架构设计 v2 — OpenCode Relay

> 完整方案见 `方案.md`（1887 行），本文档为结构化摘要。

## 架构图

```
手机浏览器 ── REST/SSE ──► 代理(3456) ──► opencode serve(4097)
                              │
                              ├─ 管理 DB 副本生命周期
                              ├─ Token 鉴权
                              └─ 静态文件服务
```

## 核心决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 代理层 | 保留薄代理层 | 密码不暴露前端、管理 serve 生命周期、单端口 |
| 前端技术 | 纯 HTML/CSS/JS 单文件 | 零构建、即改即生效 |
| 通信协议 | REST + SSE | opencode serve 原生 SSE，无需 WebSocket |
| 数据隔离 | 启动时复制 Desktop DB | Desktop DB 零风险 |
| SSE 实现 | fetch + ReadableStream | 支持自定义 header（EventSource 不支持） |

## 数据流

1. 启动：复制 `~/.local/share/opencode/opencode.db` → `relay-data/relay.db`
2. 消息：手机 POST → 代理鉴权 → 转发 serve → SSE 流式返回
3. 关闭：taskkill serve → 删除 relay.db

## 关键约束

- Windows 兼容：shell:true + taskkill /F
- Basic Auth 用户名必须是 `opencode`
- SSE 不能 buffer，必须 pipe
- 同源部署，无 CORS
