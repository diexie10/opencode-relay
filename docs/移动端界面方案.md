# 手机端界面改造方案

## 现状
- 手机端是一个 xterm.js 终端模拟器
- 显示 opencode 的 TUI 输出（ANSI 控制码、光标定位、旋转动画等）
- 功能正确但不够友好

## 目标
做一个像 OpenCode 桌面版那样的移动端界面

## 核心矛盾
opencode CLI 用的是 **TUI（终端界面）**，输出带大量 ANSI 控制码。
```
收到的是: \e[38;2;255;255;255m 正在分析... \e[23;30H⠋
而不是:   { "type": "message", "content": "正在分析..." }
```
所以**不能直接解析成聊天气泡**，xterm.js 仍是正确渲染它的唯一方式。

## 方案

### 两层结构

```
┌───────────────────────────────┐
│  App Shell（我控制）            │  ← 漂亮的 App 外壳
│  ┌─────────────────────────┐  │
│  │  Terminal View（xterm）  │  │  ← 内核还是 xterm
│  └─────────────────────────┘  │
│  Bottom bar（我控制）          │  ← 输入 + 工具栏
├───────────────────────────────┤
│  导航: 对话 | 历史 | 设置      │
└───────────────────────────────┘
```

### 界面布局

```
┌─ 状态栏 ─────────────────────┐
│  ☰           OpenCode    ⚙️  │
│  ● 已连接  运行 5 分钟        │
├─ 对话标签 ───────────────────┤
│  [终端]  [历史]              │
├─ 主区域 ─────────────────────┤
│                              │
│  终端显示区 (xterm.js)        │
│  - opencode 的完整 TUI       │
│  - 自动滚动跟随              │
│  - 触摸滑动回看              │
│                              │
├─ 快捷工具栏 ─────────────────┤
│  [Esc] [Tab] [Ctrl+C] [↑↓]  │
├─ 输入栏 ─────────────────────┤
│  ▷ 输入消息...        [发送] │
└──────────────────────────────┘
```

### 对话历史

```
[终端]  [历史]          ← 两个 tab
                      ← 历史 tab 显示
┌─ Session 3 ─────────┐
│ 今天 18:36 - opencode │  ← 点击进入只读回放
│ 运行 8 分钟          │
├──────────────────────┤
│ Session 2            │
│ 今天 17:20 - bash    │
│ 运行 3 分钟          │
├──────────────────────┤
│ Session 1            │
│ 2026/7/27 - opencode │
│ 运行 12 分钟         │
└──────────────────────┘
```

### 颜色主题
- 匹配 OpenCode 桌面版风格
- 深色背景 (#0a0a0a / #141414)
- 橙色强调 (#f5a623)
- 绿色运行状态 (#4caf50)

## 需要做的改动

### 前端 (public/index.html) — @designer 负责
- 完全重写为 App Shell 架构
- 添加 Tab 导航（终端 / 历史 / 设置）
- 美化状态栏、工具栏、输入栏
- PWA 支持（添加到桌面）

### 后端 (server.js) — 我负责
- 加 session 日志（按文件存储）
- 加 API：`GET /api/sessions` 获取历史列表
- 加 API：`GET /api/sessions/:id` 获取某次会话输出

## 不做的
- ❌ 不解析 TUI 输出为结构化消息（脆弱、容易随 opencode 更新而坏）
- ❌ 不添加数据库（保持文件级存储，零依赖）
- ❌ 不添加通知推送（需要 HTTPS + 证书，Tailscale 不支持）
